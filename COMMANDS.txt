================================================================================
PERF PROFILE (--profile perf / --profile all)
================================================================================
Window ≤ 30 min  → --per-process (one row per process per interval)
Window 30min–2h  → --per-role    (one row per role: DRIVES/COMPUTE/FRONTEND)
Window > 2h or default → cluster average (one row per interval)

Stats collected (all three tiers use the same stat list, different granularity):
  CPU_UTILIZATION
  SSD_READ_LATENCY, SSD_WRITE_LATENCY
  DRIVE_READ_LATENCY, DRIVE_WRITE_LATENCY
  SSD_READ_REQS, SSD_WRITES, SSD_BLOCKS_READ, SSD_BLOCKS_WRITTEN
  DRIVE_READ_OPS, DRIVE_WRITE_OPS, DRIVE_LOAD, DRIVE_ACTIVE_IOS
  ops: READS, WRITES, READ_LATENCY, WRITE_LATENCY, READ_BYTES, WRITE_BYTES, OPS, THROUGHPUT
  ops_driver: READS, WRITES, READ_BYTES, WRITE_BYTES, THROUGHPUT
  GOODPUT_TX_RATIO, GOODPUT_RX_RATIO, PORT_TX_BYTES, PORT_RX_BYTES
  DROPPED_PACKETS, CORRUPT_PACKETS
  JRPC_SERVER_PROCESSING_AVG, JRPC_SERVER_PROCESSING_TIME, JRPC_SERVER_CALLS_CLIENT_SUPPORTS_QOS
  CLIENT_RPC_CALLS, CLIENT_ROUNDTRIP_AVG, SERVER_RPC_CALLS, SERVER_PROCESSING_AVG, CLIENT_RECEIVED_TIMEOUTS
  weka stats realtime -s -cpu
